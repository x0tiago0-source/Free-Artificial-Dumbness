# Privacy Policy

**Last updated:** 15 August 2026

Free Artificial Dumbness is an Android application that helps users reduce exposure to selected artificial-intelligence surfaces inside supported social-media applications. This policy describes the current local implementation.

## Summary

- The application does not create user accounts.
- The application does not require a login.
- The application does not operate a backend service.
- The application does not include analytics or advertising SDKs.
- The application does not request the Android `INTERNET` permission.
- Preferences and the latest block summary are stored locally on the device.
- Accessibility content is processed locally and is not transmitted by the application.

## Accessibility Service

The application requires the user to enable its Android Accessibility Service. The service is used to:

- inspect accessibility nodes exposed by the supported applications;
- identify configured AI labels and surfaces;
- navigate back from a blocked context when appropriate;
- display a local blocking overlay;
- record the latest local block summary and timestamp.

The service is restricted to these application packages in its configuration:

- `com.whatsapp`;
- `com.instagram.android`;
- `com.facebook.katana`;
- `com.twitter.android`.

The application does not intentionally inspect unrelated applications.

## Data stored locally

The application uses Android DataStore Preferences with the local store `focus_app_preferences`. It stores:

- the enabled/disabled state of each app toggle;
- a short summary of the latest detected block;
- the timestamp of the latest detected block.

The latest block summary is generated by the application from its own app and rule labels. Accessibility node content is not sent to a remote server and is not stored as a browsing history.

## Data sharing and third parties

The current implementation contains no application backend, account integration, advertising SDK, analytics SDK or network client. No personal information is sold, rented or shared by the application.

Third-party applications remain subject to their own privacy policies. Free Artificial Dumbness does not control what those applications collect.

## Declared Android permissions

The manifest currently declares `FOREGROUND_SERVICE` and `POST_NOTIFICATIONS`. The current implementation does not create a separate foreground service or send application notifications. These declarations must be reviewed before a production release; if either permission becomes functional, this policy must be updated to explain its purpose.

The Accessibility Service binding permission is used by Android to expose the service in system Accessibility settings.

## Retention and deletion

Local preferences remain on the device until the user clears the application data or uninstalls the application. No remote copy is created by the current implementation.

## Children

The application is not specifically directed at children and does not intentionally collect personal information from children.

## Changes to this policy

This policy must be updated before introducing accounts, cloud synchronisation, analytics, advertising, remote diagnostics or any new data access. The date at the top should be changed whenever the processing behaviour changes.
